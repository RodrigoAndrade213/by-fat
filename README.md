# By Fat - Sistema Web para Controle de Peso e Registro de Refeições

Sistema desenvolvido como trabalho final da disciplina **Desenvolvimento de Aplicação Web** - Uniasselvi 2025.

## Funcionalidades
- Cadastro e login seguro (BCRYPT + PDO)
- Cadastro de alimentos com calorias por unidade
- Registro de refeições com cálculo automático em tempo real (JavaScript)
- Dashboard com gráfico de calorias diárias e barra de progresso
- Design responsivo com efeito glassmorphism
- Histórico completo de refeições

## Tecnologias
- PHP 8.2
- MySQL 8.0
- HTML5 / CSS3 / JavaScript
- XAMPP (ambiente local)

## Como executar
1. Coloque a pasta no `htdocs` do XAMPP
2. Importe o arquivo `by_fat.sql` no phpMyAdmin
3. Acesse: http://localhost/by-fat
